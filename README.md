🚨 Road Accident Analysis

An end-to-end data analytics project focused on analyzing road accident data, identifying patterns and key factors associated with accidents, and presenting actionable insights through an interactive Power BI dashboard.

📌 Project Overview

This project covers the complete data analytics workflow, starting from raw road accident data and ending with an interactive Power BI dashboard.

The project includes:

Data understanding and exploration

Data cleaning and preprocessing using Python

Exploratory Data Analysis (EDA)

Data transformation and preparation

Data modeling in Power BI

DAX calculations and KPIs

Interactive visualizations

Final dashboard development in Power BI

🎯 Project Objectives

The main objectives of this project are:

Analyze the overall number of road accidents and casualties

Understand accident severity and its distribution

Identify patterns based on vehicle types

Analyze road and weather conditions

Compare accidents across different locations/categories

Identify trends in accidents and casualties

Create an interactive dashboard for easy business-style analysis

🛠️ Tools & Technologies

Python — Data cleaning, preprocessing and exploratory data analysis

Matplotlib — Data visualization during analysis

Seaborn — Statistical and exploratory visualizations

Microsoft Power BI — Data modeling and dashboard development

🐍 1. Data Cleaning & Preprocessing Using Python

The raw road accident dataset was first analyzed and prepared using Python.

Tasks performed:

Loaded the dataset using Pandas

Inspected rows, columns and data types

Checked missing values

Identified duplicate records

Handled inconsistent or incorrect data

Converted columns into appropriate data types

Cleaned categorical values

Prepared the dataset for further analysis

Example Python libraries used:

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns

📊 2. Exploratory Data Analysis

After cleaning the data, exploratory analysis was performed to understand the underlying patterns in the dataset.

The analysis focused on areas such as:

Accident frequency

Casualty distribution

Accident severity

Vehicle categories

Road conditions

Weather conditions

Location-related patterns

Trends over time

Python visualizations were used to identify patterns and understand relationships between different variables.

🔍 3. Data Preparation for Power BI

After completing the initial analysis and preprocessing, the cleaned dataset was prepared for Power BI.

The dataset was checked to ensure that:

Required columns were available

Data types were appropriate

Categorical values were consistent

Unnecessary fields were removed where required

The data structure was suitable for visualization and analysis

⚡ 4. Power BI Data Transformation

The prepared dataset was imported into Microsoft Power BI.

Power Query was used where required for:

Data transformation

Column formatting

Data type conversion

Cleaning values

Creating required fields

Preparing the final dataset for modeling

🧩 5. Data Modeling

The data was structured inside Power BI to support efficient analysis and visualization.

The modeling process included:

Understanding relationships between tables

Creating appropriate fields

Organizing dimensions and measures

Preparing the data model for dashboard reporting

🧮 6. DAX Measures & KPIs

DAX was used to create calculated measures and key performance indicators required for the dashboard.

Examples of metrics analyzed include:

Total Accidents

Total Casualties

Fatal Casualties

Serious Casualties

Slight Casualties

Accident-related percentages

Category-wise measures

These measures were then used throughout the Power BI visuals.

📈 7. Power BI Visualizations

Different Power BI visuals were used to present the accident data in an easy-to-understand format.

The dashboard includes analysis related to:

Total accidents and casualties

Accident severity

Vehicle type

Road conditions

Weather conditions

Location/category analysis

Accident trends

KPI cards

Interactive filters and slicers

🎨 8. Dashboard Development

The final stage of the project was designing an interactive Power BI dashboard.

The dashboard was designed with a focus on:

Clear KPI presentation

Easy navigation

Meaningful visualizations

Consistent formatting

Interactive filtering

Simple and readable layout

Users can interact with the dashboard using filters and slicers to explore different aspects of road accident data.
